## Техническое задание

1. **Назначение.** Плагин для VS Code, который оценивает сложность функций C++: помогает найти запутанные функции.
2. **Среда и язык.** IDE: Visual Studio Code. Язык разработки плагина: TypeScript. Анализируемый язык: C++.
3. **Команда.** В палитре команд (Ctrl+Shift+P) доступна команда **Analyze Complexity**.
4. **Поиск функций.** Функции, методы и конструкторы берутся из списка символов VS Code (его даёт расширение C/C++). Объявления без тела пропускаются.
5. **Разбор текста.** Собственный разборщик выделяет слова, операторы и фигурные скобки. Комментарии, строки и символьные литералы пропускаются.
6. **Метрики для каждой функции:**
   - цикломатическая сложность = 1 + число `if`, `for`, `while`, `case`, `catch`, `&&`, `||`, `?` в теле функции;
   - максимальная вложенность блоков (считается по стеку фигурных скобок, внешние скобки функции не учитываются).
7. **Вывод.** Для каждой функции в панель Output выводятся имя, номер строки, сложность и вложенность.
8. **Обработка ошибок.** Если файл не открыт, показывается предупреждение. Если функции не найдены, выводится подсказка.
